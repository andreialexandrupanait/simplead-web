# Imagini pentru pagina de login

Pune aici imaginile caruselului din `/admin/login`:

- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`
- `slide-4.jpg`

Recomandări: format landscape/portret mare (ex. 1200×1600 sau 1600×1200), JPG optimizat
(sub ~300 KB fiecare). Dacă un fișier lipsește, se afișează un gradient navy de fundal —
pagina rămâne funcțională.

Titlurile/subtitlurile slide-urilor se editează în `src/pages/admin/login.astro` (array-ul `slides`).
